## Status Key
- `[OPEN]`: Reported, not yet actively diagnosed.
- `[INVESTIGATING]`: Actively testing hypotheses and logging results.
- `[WORKAROUND_APPLIED]`: Temporary mitigation in place; root cause fix pending.
- `[RESOLVED]`: Definitively fixed with verified code and regression tests.
- `[BLOCKED]`: Waiting for hardware, third-party fix, or user input.
